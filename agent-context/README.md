# agent-context/

Context for developer agents working in this repo. Collected and maintained by Lyra for Chama.

The rule: document everything, even what we cannot build with today's technology and AI. One day it becomes possible, and the spec is already waiting.

## Layout

- `specs/` - studies of other products, approaches and designs worth borrowing
- `resources/` - best external resources: links, references, notes
- `tests/` - test ideas, eval prompts, verification results
- `shared/` - things Chama shares (links, screenshots, notes) that still need filing

## Rules

- Every claim is tagged: plain text means SOURCED from a named resource, `*(our read)*` means inferred.
- Keep what we cannot build yet; mark it `not buildable today` with one line on why.
- Cross-project items (not tied to this repo) go to the central private `spec-library` repo instead.
- This repo is public: keep only public-safe material here. Anything private goes to the private spec-library repo, never here.
